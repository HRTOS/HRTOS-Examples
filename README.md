# HRTOS Examples

**HRTOS 官方示例与驱动组件仓库**

HRTOS Examples 是 HRTOS 实时操作系统的官方示例仓库，提供面向 8051（MCS-51）单片机的示例源码、内核机制演示程序、硬件驱动组件及相关工程文件。

本仓库围绕 HRTOS 的实际使用与工程开发，构建从基础功能学习、任务调度分析到外设驱动集成的完整示例体系。开发者可以通过示例代码了解操作系统接口的使用方法，观察任务调度与任务间通信的运行过程，并将配套驱动应用于实际嵌入式项目。

仓库主要包含三个部分：

- **Basic**：HRTOS 基础功能与核心机制示例。
- **Task**：任务模型、调度算法、资源管理、中断及内核行为分析示例。
- **Driver**：面向常用 8051 外设的模块化驱动组件及配套工程。

HRTOS Examples 不仅用于展示 API 的调用方式，也注重呈现操作系统机制与实际硬件应用之间的联系，为系统学习、功能验证和工程开发提供可参考的代码基础。

## 项目简介

HRTOS（Hard Real-Time Operating System）是一款面向 8051 单片机的实时操作系统。

HRTOS 提供任务管理、优先级调度、时间管理、任务间通信、同步控制及中断协作等系统机制。围绕这些能力，本仓库通过可阅读、可编译和可扩展的示例程序，展示相关功能在具体程序中的组织方式与使用方法。

本仓库的建设重点包括：

- **内核功能示例化**：通过独立示例展示任务创建、任务删除、任务抢占、时间片调度、快速任务及其他系统机制。
- **调度过程可观察**：通过任务执行、优先级调度和实时行为示例，帮助开发者理解任务之间的执行关系。
- **通信与同步机制实践**：涵盖事件、信号量、互斥锁、消息队列和邮箱等机制。
- **系统资源与中断分析**：围绕任务状态、上下文切换、资源管理、中断嵌套及相关运行行为提供分析示例。
- **常用硬件驱动组件**：提供基础输入输出、显示、传感器、控制和存储等外设的驱动源码。
- **面向工程的组织方式**：配套头文件、源码、Keil C51 工程及部分编译产物，便于阅读、验证和二次开发。

## 示例内容

### 1. Basic：基础功能示例

`Basic/` 面向初次接触 HRTOS 的开发者，通过独立的示例程序展示操作系统的主要功能及常见 API 的使用方式。

| 示例目录 | 主要内容 |
|---|---|
| `01_Hello_HRTOS` | HRTOS 基础启动与运行 |
| `02_Hello_Event` | 事件机制 |
| `03_Hello_Interrupt` | 中断处理 |
| `04_HRTOS_TaskDelete` | 任务删除 |
| `05_HRTOS_TaskPreempt` | 任务抢占 |
| `06_HRTOS_TimeSlice` | 时间片调度 |
| `07_HRTOS_Semaphore` | 信号量 |
| `08_HRTOS_Mutex` | 互斥锁 |
| `09_HRTOS_MessageQueue` | 消息队列 |
| `10_HRTOS_Mailbox` | 邮箱 |
| `11_HRTOS_FastTask` | 快速任务 |
| `12_HRTOS_TaskSetNext` | 任务切换控制 |
| `13_HRTOS_InterruptNesting` | 中断嵌套 |

每个示例围绕特定功能展开，便于开发者独立阅读和进行实验。建议按照目录编号逐步学习，从基础运行流程开始，再进入调度、通信和中断等内容。

### 2. Task：内核机制与运行行为示例

`Task/` 面向希望深入理解 HRTOS 内部机制的开发者，重点关注任务执行模型、调度行为、时间控制、系统资源及中断驱动等主题。

#### 任务执行与状态管理

目录：`01-task-execution/`

包括：

- `create-task.c`：任务创建
- `context-switch.c`：上下文切换
- `task-state.c`：任务状态管理
- `priority-inheritance.c`：优先级继承

#### 调度机制

目录：`02-scheduling-engine/`

包括：

- `priority-demo.c`：优先级调度
- `real-time-demo.c`：实时调度相关演示
- `rr-demo.c`：轮转调度演示
- `starvation-demo.c`：任务饥饿相关演示

#### 任务间通信与同步

目录：`03-communication-model/`

包括：

- `semaphore.c`：信号量
- `mutex.c`：互斥锁
- `message-queue.c`：消息队列
- `mailbox.c`：邮箱

#### 时间控制

目录：`04-time-control/`

包括：

- `tick-system.c`：系统时基
- `timer-demo.c`：定时机制
- `delay-vs-wait.c`：延时与等待机制对比

#### 系统资源管理

目录：`05-system-resource/`

包括：

- `allocation.c`：资源分配
- `fragmentation.c`：内存碎片相关分析
- `stack-overflow.c`：栈溢出相关分析

#### 中断驱动

目录：`06-interrupt-driven/`

包括：

- `interrupt-entry.c`：中断入口
- `latency-test.c`：中断延迟测试
- `nested-interrupt.c`：嵌套中断

#### 内核行为分析

目录：`07-kernel-behavior/`

包括：

- `full-schedule-flow.c`：完整调度流程
- `priority-inversion.c`：优先级反转

Task 部分强调从代码层面理解内核行为。相关示例可用于学习、实验和辅助分析；涉及具体时序、性能指标或功能保证时，应结合实际硬件、编译配置、系统版本及测试结果进行验证。

### 3. Driver：硬件驱动组件

`Driver/` 提供面向 8051 单片机常用外设的驱动组件，按照功能分类组织源码、接口头文件及相关工程。

驱动部分不仅提供单个外设的操作函数，也通过统一的组件分类与头文件组织方式，方便开发者在应用程序中选择所需模块，并根据目标硬件进行配置和集成。

#### Basic：基础输入输出

涵盖：

- LED 控制
- 独立按键
- 矩阵键盘
- 蜂鸣器
- 外部中断
- 定时器相关功能

#### Display：显示设备

涵盖：

- LCD1602
- OLED
- 数码管

相关源码包含显示初始化、数据写入、字符与字符串显示、位置设置及其他显示操作。

#### Sensor：传感器与数据采集

涵盖：

- ADC 数据采集
- DHT11 温湿度传感器
- DS1302 实时时钟
- DS18B20 温度传感器
- HC-SR04 超声波测距
- HC-SR501 人体感应
- 红外传感器
- 土壤湿度传感器
- YL-83 雨滴传感器

此外，相关工程文件中还包含 XPT2046 触摸控制器相关实现。

#### Control：控制类组件

涵盖：

- PWM 控制
- 继电器控制

#### Storage：存储与总线组件

涵盖：

- 24C02 EEPROM
- I²C 通信相关实现

驱动目录主要由以下部分组成：

| 目录 | 用途 |
|---|---|
| `Driver/APP/` | 驱动演示应用与综合示例 |
| `Driver/Inc/` | 驱动组件接口头文件 |
| `Driver/Src/` | 驱动源码及功能模块实现 |
| `Driver/Project/` | 分类驱动工程及相关工程文件 |

驱动的实际适用范围取决于目标 MCU、外设型号、引脚连接、时钟配置和相关硬件条件。集成前应查阅对应头文件与源码，并根据实际电路完成必要的配置。

## 如何使用

### 第一步：获取示例

获取 HRTOS Examples 仓库，并根据需要选择 `Basic/`、`Task/` 或 `Driver/` 中的内容。

### 第二步：准备 HRTOS 开发环境

根据目标芯片及所使用的 HRTOS 版本，准备相应的内核文件、头文件、配置参数和编译环境。

### 第三步：打开工程或查看源码

对于包含 Keil 工程文件的示例，可以使用 Keil μVision 打开对应工程；对于独立的 C 源文件，可以结合相应的系统配置和头文件进行阅读与集成。

### 第四步：检查硬件与编译配置

确认 MCU 型号、晶振频率、存储器配置、引脚分配、中断配置以及驱动依赖，并根据实际开发板调整相关代码。

### 第五步：编译、下载与验证

完成配置后进行编译，并将程序下载到目标设备。对于调度、中断和时间控制等示例，应通过适当的调试手段或测量设备观察运行结果。

## 推荐学习路径

**入门阶段：** 从 `Basic/01_Hello_HRTOS` 开始，逐步学习事件、中断、任务管理、调度和通信机制。

**功能应用阶段：** 结合具体需求选择 `Driver/` 中的外设组件，了解接口定义、初始化流程及硬件依赖。

**内核学习阶段：** 阅读 `Task/` 中的任务执行、调度引擎、通信模型、时间控制和系统资源示例，进一步理解实时操作系统的内部运行机制。

**工程实践阶段：** 将任务管理、同步通信和外设驱动结合起来，构建具有多个独立功能模块的嵌入式应用。

## 关于 HRTOS

HRTOS（Hard Real-Time Operating System）是一款面向 8051 单片机的实时操作系统，围绕任务调度、任务管理、时间服务、同步通信和中断协作等机制构建完整的系统功能体系。

HRTOS 的工程体系不仅包括内核与 API，还包括系统设计文档、扩展模块、驱动组件和应用示例。HRTOS Examples 是这一体系的重要组成部分，用于将系统接口、内核机制与实际应用代码联系起来。

本仓库重点展示 HRTOS 的使用方式和工程实践。具体功能、配置要求、资源限制及实时性能，应以相应版本的官方文档、源代码和实际测试结果为准。
