# HRTOS Examples

HRTOS 官方应用示例仓库。

本仓库提供基于 **51 单片机 HRTOS** 的示例源码，用于展示 HRTOS 实时操作系统的基础使用方法、任务调度机制以及内核功能特性。

## 示例内容

### Basic

基础入门示例，用于快速了解 HRTOS 系统运行方式。

包含：

- HRTOS 基础启动
- 事件机制示例
- 中断处理示例

### Task

任务调度示例，用于深入学习 HRTOS 任务管理和实时调度机制。

包含：

- 任务创建与执行
- 上下文切换
- 优先级调度
- 时间管理
- 任务通信
- 系统资源管理
- 中断驱动模型
- 内核行为分析

### Application

综合应用示例。

用于展示 HRTOS 在实际嵌入式应用场景中的使用方式。


## 使用环境

- MCU：51 单片机
- RTOS：HRTOS
- 编译环境：Keil C51


## 关于 HRTOS

HRTOS（Hard Real-Time Operating System）是一款面向 51 单片机设计的轻量级硬实时操作系统。
